# MaidsWithGuns Company Website

Root GitHub Pages site for `maidswithguns.com`.

- `/` redirects to `/maid-supremacy/`
- `/maid-supremacy/` serves the Maid Supremacy website directly
- `/s-prysm-destroyer/` serves the S. Prysm Destroyer website directly
- `/portfolio/` serves the MaidsWithGuns freelance game developer portfolio

Build each game website with its `homepage` set to the matching custom-domain
subpath, then copy the build output into the matching folder here.
